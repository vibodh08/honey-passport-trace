# Honey Passport Trace

Create a responsive React + TypeScript page for HoneyChain called "Honey Passport".

This is the public-facing page that a customer will see after scanning a QR code on a honey bottle.

Create a route:

 /passport/:batchId

The page should have:

- HoneyChain logo/name

- Title: "Honey Passport"

- Subtitle: "From Hive to Jar — Verified."

A batch information card containing:

- Batch ID

- Beekeeper Name

- Location

- Hive ID

- Honey Type

- Harvest Date

- Quantity

- Current Status

Create a visual supply-chain timeline:

🐝 Harvested

↓

🏭 Extracted

↓

⚙️ Processed

↓

🧪 Lab Tested

↓

🍯 Bottled

↓

🚚 Distributed

Completed stages should have a green checkmark.

Also show:

- "Traceability Verified" status

- Blockchain verification section

- A section for lab/testing information

- A section showing originating hive information

Use realistic mock data initially:

Batch ID: HC-2026-0002

Beekeeper: Ravi Kumar

Location: Coorg

Hive ID: HIVE-002

Honey Type: Wildflower

Harvest Date: 2026-09-04

Quantity: 20 kg

Status: Harvested

Make the UI look professional and suitable for a Smart India Hackathon project.

Use a clean honey/agriculture + blockchain technology aesthetic.

Do not create a backend. Use mock data for now.
